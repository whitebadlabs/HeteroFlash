# Publication scaffold

`main.tex` is a structured **methods/proposal draft**, not a completed paper with empirical results. It is written to avoid fabricated benchmarks or novelty claims. Complete measured results and citations before any arXiv submission.

Build (self-contained references): `pdflatex main.tex && pdflatex main.tex`. The BibTeX source is retained separately for future journal/arXiv tooling.

Before preprint submission, replace placeholder author metadata, update related work, freeze preregistration and hypothesis table, add real experiments/figures and error bars, disclose model/data licenses, and add artifact availability statement.
